Налаштувати OSPF
__________________________________________________________________________
R1(config-if)#ip ospf 1 area 0 (включити ospf на інтерфейсі)

R1(config-if)# ip ospf priority 255 (Визначення голоіного роутера(0-255) 255 = DR

R1(config)#router ospf 1
R1(config-router)#router-id 1.1.1.1 (Явно налаштувати ідентифікатор для маршрутизатора) == Визначення голоіного роутера(2.2.2.2)
__________________________________________________________________________


clear ip ospf process (Очистити процес OSPF)


Router(config)# interface gigabitethernet 0/0
Router(config-if)# ip ospf cost 50
