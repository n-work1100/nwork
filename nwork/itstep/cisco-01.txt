Описання протоколу IP(Internet Protocol)

--TCP--
Transmission Control Protocol
Протокол передачі даних

--LAN--
Local Area Network
Локальна комп'ютерна мережа

--NIC--
Network Interface Controller
Мережевий адаптер

--WAN--
Wide Area Network
Глобальна комп'ютерна мережа

-- ARP --
Address Resolution Protocol
Это сетевой протокол, который нужен для связи логического IP-адреса с физическим MAC-адресом устройства в локальной сети. Он помогает компьютерам узнать, какому конкретно «железу» принадлежит нужный IP-адрес.

-- VRRP --
Virtual Router Redundancy Protocol
Это сетевой протокол для создания отказоустойчивых сетей.
Он объединяет несколько физических маршрутизаторов в один виртуальный с общим IP-адресом,
который компьютеры используют как шлюз по умолчанию.
Если главный роутер ломается, резервный мгновенно берет его адрес на себя

-- HSRP --
Hot Standby Router Protocol
Це мережевий протокол від компанії Cisco для захисту від збоїв.
Він об'єднує кілька маршрутизаторів у віртуальну групу, яка має одну загальну IP-адресу.
Ця адреса працює як шлюз за замовчуванням для комп'ютерів у мережі

-- DHCP --
Dynamic Host Configuration Protocol
Это сетевой протокол, который автоматически дает устройствам IP-адреса и другие данные для работы в интернете.
Без него пришлось бы настраивать каждый компьютер или телефон вручную.

-- TTL --
Time to Live
«время жизни»

-- BPDU --
Bridge Protocol Data Unit
Це службові кадри, які комутатори використовують для роботи протоколу STP (Spanning Tree Protocol).
Вони потрібні для пошуку петель у мережі, вибору головного комутатора (Root Bridge) та налаштування безпечних шляхів передачі даних.

--IETF--
Internet Engineering Task Force
Інженерна робоча група що підтримує работу протоколів TCP/IP

--ICANN--
Internet Corporation for Names and Numbers

--IAB--
Internet Architecture
Організації, створені для підтримки структури та стандартизації интернет протоколів і процесів

--DSL--
Digital Subscriber Line
Цифрова абонентсяка лінія - це технологія, яка дозволяє передавати дані через звичайні мідні телефонні дроти

--UDP--
User Datagram Protocol (port:67)
Протокол датаграм користувача — це швидкий транспортний мережевий протокол, який передає дані без встановлення з'єднання та перевірки їхньої доставки

--Чотири основіні характеристики, яким повинні відповідати мережні архітектури--
* Відмовостійкість
	-- Обмежує кількість пристроїв
	-- Декілька шляхів

* Маштабованість
	-- Маштабована мережа швидко розгортається для підтримки служб, до яких звертаються уже залучені користувачі

* Якість обслуговування (QoS)
	-- Quality of Service

* Безпека, три основні вимоги
	--Конфіденційність
	--Цілісність
	--Доступність

--Тенденції мереж, які впливають на організації та споживачів--
* BYOD - Bring Your Own Device
	--Використання власного пристрою

* Онлайн-співпраця

* Відео-зв'язок

* Хмарні обчислення
